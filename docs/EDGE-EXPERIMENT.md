# Freecam Edge — эксперимент одного видеопотока

Статус: локальный прототип в `experimental`. Нативный аддон OBS для живых источников пока не реализован. Доставка через Twitch ещё не проверена. В `main` эксперимент не включён.

Обычный зритель получает привычную игру с камерой и рамкой с фрагментами изображения. Расширение извлекает из этой рамки фон под исходной камерой, восстанавливает его и отображает перемещаемую камеру. Игра, фон и камера относятся к одному декодированному кадру, звук остаётся у исходного плеера. Дополнительного видеосоединения или сервера раздачи нет.

Чтобы не обрезать края игры, полный кадр игры вписывается внутрь рамки. Это сохраняет обзор, но уменьшает разрешение. Точное сохранение всех исходных пикселей 1080p при добавлении камеры в тот же кадр не заявляется.

| Профиль | Игра | Камера | Передаваемый фон | Рамка сверху / сбоку |
|---|---|---|---|---|
| Full | 1792×1008 | 640×360 | 640×360 | 36 / 64 px |
| Compact | 1856×1044 | 640×360 | 320×180 | 18 / 32 px |

Передача: полосы высотой 16 px, разложенные в заранее известном порядке по нижнему, верхнему и боковым краям. Последняя полоса дополнена до 16 px; дополнение не используется при восстановлении. Цветовая подпись идентифицирует профиль. Это не проверка целостности: наличие подписи не гарантирует сохранность каждого фрагмента после сжатия. Метаданные о положении камеры в этой версии фиксированы; произвольная камера и движущаяся исходная рамка пока не поддерживаются. Свободные области заполняются тёмным цветом. Видимость рамки и дополнительная нагрузка на видеокодек являются ограничениями.

## Локальное сравнение

1. `npm run dev`.
2. `node scripts/generate-edge-lab.mjs --game "путь к игровому ролику" --camera "путь к ролику камеры"` (нужны FFmpeg и Edge).
3. Открыть `http://127.0.0.1:5173/edge-lab.html`.

Стенд показывает обычный вид, прежнюю компоновку Packed, Full и Compact. Переключатель показывает вид с расширением. Подвижные камеры можно перетаскивать и скрывать. Общая шкала времени позволяет сравнить остановленный момент. Обычный вид и Packed нарисованы из исходных локальных клипов; Full и Compact декодируются из сжатых MP4. Это демонстрация компоновки, а не равные условия кодирования для четырёх панелей. Отдельные локальные видео при воспроизведении могут расходиться по времени; для точного визуального сравнения нужно остановить и выбрать момент шкалой. В рабочем транспорте камера и фон берутся из одного кадра.

В `artifacts/edge-lab/` сохраняются 30 FPS ролики и результаты. Full/Compact кодируются в H.264 1080p с целевыми 6 Мбит/с; из полученного видео повторно кодируются 720p/3 Мбит/с и 480p/1,5 Мбит/с. Эта имитация не воспроизводит точные настройки Twitch. `report.json` содержит средний PSNR участка по семи кадрам каждого профиля и качества, относительно вписанного исходного игрового видео. Метрика не оценивает привлекательность рамки и не заменяет просмотр.

Проверки: `npm test`, `npm run build`, `node scripts/test-edge-lab.mjs`. Последняя проверяет точное восстановление синтетического кадра до сжатия, работу общего контроллера, перемещение/скрытие камеры, возврат оригинала и отказ на видео без маркера.

## Проверка через OBS и Twitch

Для первой проверки живой аддон не нужен: созданный `full-1080.mp4` уже содержит готовый единый видеопоток.

1. Создать отдельную сцену OBS «Freecam Edge Test».
2. Источники / Sources → + → Источник медиа / Media Source → Локальный файл / Local File: `artifacts/edge-lab/full-1080.mp4`.
3. Включить Повтор / Loop. Вписать в экран 1920×1080. У клипа нет звука.
4. Не включать старую сцену Freecam или Dual Format: для этой проверки нужен обычный горизонтальный поток.
5. Запустить тестовый эфир вручную. В обычном браузере оценить рамку. В браузере с экспериментальной версией расширения проверить восстановление, движение камеры, паузу, рекламу и переключение качества. При потере подписи контроллер возвращает исходное видео; повреждение самого участка по подписи определить нельзя.

Ролики короткие и повторяются каждые четыре секунды — это стенд. Для вывода о продукте нужны продолжительный живой эфир, несколько игр, разные размеры камер, оценка CPU/GPU и независимые зрители на телефонах/ТВ. Нельзя считать эксперимент готовым решением только по наличию восстановленной картинки.
