# Freecam SEI — кандидат релиза

Публикация релиза не выполнена. Эта сборка предназначена для повторного теста перед выпуском.

## Выполнено локально

- README описывает текущую функцию и отдельно объясняет упаковку фона в данные видео.
- Главная презентация показывает реальную распаковку SEI; сравнения с прежними вариантами убраны.
- Обновлены окно расширения, состояния подключения и диагностика.
- Анимации применяются к наведению, фокусу и захвату камеры; видео не получает анимационного смещения времени.
- Поддерживается prefers-reduced-motion и перемещение камеры стрелками.
- Понижен слой собственного виджета; локальная проверка клика по внешней панели прошла. Это не подтверждение совместимости с Chatterino+.
- Пройдены тесты установленного MV3-расширения на MSE-стенде: 96 кадров, одно получение видео, перемещение мышью/клавиатурой, отключённая анимация, внешняя панель, возврат исходного вида без SEI.
- Пройдены проверки интерфейса окна расширения с имитацией сообщений; настоящая связь со страницей проверяется отдельно в MV3-тесте.

## До выпуска

- Повторный живой тест текущей сборки на Twitch с Chatterino+ и штатными кнопками плеера.
- Устранение и повторная проверка видимого шва восстановленного участка.
- Длительный эфир: нагрузка, рост памяти, пауза/возврат к эфиру, полноэкранный режим и смена качества.
- Измерение дополнительной задержки и липсинка на реальном выводе устройства.
- Проверка исходного качества и корректного возврата обычного вида при потере данных/рекламе.
- Удобный выпуск приложения стримера: готового универсального мастера живых OBS-сцен пока нет.
- Проверка комплекта и условий публикации магазинов. Публичных карточек Chrome/Edge пока нет.

Локальный ZIP: `artifacts/Freecam-SEI-Release-Candidate.zip`. Это кандидат для ручного теста, а не объявленный стабильный релиз.
