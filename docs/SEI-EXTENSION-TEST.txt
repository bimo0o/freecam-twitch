FREECAM SEI — ТЕСТ ПЕРЕМЕЩЕНИЯ В БРАУЗЕРЕ

Версия 0.4.1 для подготовленных эфиров Freecam.

1. Chrome: chrome://extensions/ ; Edge: edge://extensions/
2. Включите «Режим разработчика / Developer mode».
3. «Загрузить распакованное / Load unpacked» → папка
   browser-extension-sei из распакованного проекта
   или artifacts/Freecam-SEI-Extension из тестового комплекта
   Выбирайте всю папку с manifest.json.
4. Откройте свой канал Twitch и ОБЯЗАТЕЛЬНО обновите страницу после установки.
5. Запустите Freecam-Twitch-Test.exe → публичный тест до 120 секунд.
   OBS не должен одновременно отправлять эфир.
6. Дождитесь тестового ролика на канале. В качестве выберите Source / Исходное.
7. Нажмите значок Freecam SEI. Дождитесь «Камера готова к перемещению».
   Перемещайте появившуюся вебку мышью. Голос остаётся у исходного плеера.

Если движения нет — пришлите текст статуса из окна расширения:
«Пакетов», «декодировано», «совпадений», «MSE-буферов» и строку ошибки.
Не присылайте ключ трансляции.

MSE-буферов 0: плеер ещё не перезапущен либо использует передачу буферов
через worker, которая этой версией пока не поддерживается.
Буферы есть, пакетов 0: проверьте Source, тестовый ролик и отсутствие рекламы.
Пакеты есть, совпадений 0: требуется проверить привязку времени к плееру Twitch.

Что уже проверено: настоящее MV3-расширение Chromium, основной мир страницы,
MediaSource/SourceBuffer, один запрос видеоданных, 96 распакованных кадров,
совпадения времени и перетаскивание. Без SEI сохраняется исходный вид.
Первый живой тест Twitch пройден на 1080p / 30 FPS. Оптимизации версии
0.4.1 проверены локально; повторная проверка этой версии в живом эфире впереди.

Для обновления уже установленного расширения: нажмите его кнопку обновления
на chrome://extensions/ или edge://extensions/, затем обновите страницу канала.

Расширение не загружает отдельную вебку/фон, не меняет звук и исходные
буферы плеера. Данные считываются до декодирования из того, что уже получает плеер.
Защищённое видео и обнаруженная реклама не обрабатываются.
