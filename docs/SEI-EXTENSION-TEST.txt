FREECAM 0.5.0 — ТЕСТОВАЯ СБОРКА

ЗРИТЕЛЮ
1. Распакуйте архив. Откройте chrome://extensions/ или edge://extensions/.
2. Включите «Режим разработчика / Developer mode».
3. «Загрузить распакованное / Load unpacked»: выберите папку с manifest.json
   (browser-extension-sei в архиве проекта или папку готового расширения).
4. Откройте подготовленный канал Freecam. ОБЯЗАТЕЛЬНО обновите страницу.
5. В качестве Twitch выберите Source / Исходное. Перетащите появившуюся вебку.
6. Наведите на неё мышь: кнопки меняют размер, скругление и возвращают в угол.

ЕСЛИ ДАННЫХ НЕТ
Откройте значок Freecam в меню расширений. Диагностика → Скопировать отчёт.
При нулевых буферах и MediaSourceHandle: Совместимость плеера → MSE в worker.
Обновите канал. Это тестовый режим. При сбое видео выключите его и обновите канал.
Включать одновременно две версии Freecam нельзя.

Буферы есть, пакетов нет: проверьте Source, поддержку Freecam на канале и рекламу.
Пакеты есть, совпадений нет: нужен отчёт с версией браузера и режимом плеера.
Пароли и ключ трансляции не присылайте.

СТРИМЕРУ
Тестовый комплект Freecam-OBS-0.5.0: Windows x64, OBS 33.0.1, 1080p30, H.264.
Сначала распакуйте весь комплект. Закройте OBS, откройте Install Freecam OBS.exe.
Выберите obs64.exe вашей установки. Запустите OBS и Freecam Native Setup.exe.
Подключитесь паролем WebSocket, выберите готовую сцену и камеру, подготовьте Freecam.
Сначала локальная запись, затем короткий эфир. Автоматического запуска эфира нет.
Подробный путь ENG/RUS: native/obs-freecam/README.md в репозитории.

ЧТО ПРОВЕРЕНО
Установленный MV3-пакет в Chromium и Edge: обычный MSE и четыре режима worker,
по 96 декодированных кадров. Classic/module и их Blob-варианты; немедленный отзыв URL.
Настоящая запись OBS с B-кадрами восстановлена из одного файла без отдельного фона.
Мастер проверен через настоящий OBS WebSocket; исходная сцена сохранена.
41 автоматический тест прошёл. Повторный живой Twitch этой версии впереди.
Совпадение PTS не является измерением задержки или липсинка.

ОГРАНИЧЕНИЯ
Alpha, не стабильный релиз. Нужен SEI-эфир; перекодирование может удалить данные.
Возможны шов восстановленного участка и пересечения со сторонними панелями.
Телефоны/ТВ показывают обычную сцену. Перемещение — Chrome/Edge на компьютере.
Поддержка worker включается отдельно; настоящий worker/CSP Twitch ещё проверяется.
OBS-профиль фона 640×360: большая область будет менее детальной.

Порог восстановления 1–100% сохраняется для всех каналов, по умолчанию 25%.
Он меняет только личный вид, не трафик стримера. Фон не загружается отдельно.
Размер 10–70% и скругление 0–48 px сохраняются для каждого канала.
