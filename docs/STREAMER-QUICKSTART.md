# Как настроить Freecam

Нужны OBS 28 или новее и Windows 10/11. Сначала остановите трансляцию и запись в OBS.

## 1. Откройте Freecam

Распакуйте скачанный ZIP: правая кнопка по архиву → **Extract All / Извлечь всё**. Откройте распакованную папку и дважды нажмите **Freecam Setup.exe**. В браузере откроется мастер. Окно приложения пока не закрывайте.

## 2. Найдите настройки в OBS

Переключитесь в OBS. В самом верху окна нажмите:

**Tools / Сервис → WebSocket Server Settings / Настройки сервера WebSocket**.

Если такого пункта нет, проверьте версию OBS: **Help / Справка → About / О программе**. Нужен OBS 28 или новее.

## 3. Включите подключение

В открывшемся окне:

1. Поставьте галочку **Enable WebSocket server / Включить сервер WebSocket**.
2. Оставьте галочку **Enable Authentication / Включить аутентификацию** включённой.
3. Оставьте **Server Port / Порт сервера** равным **4455**. Если там уже другой порт, введите такой же в Freecam.

## 4. Скопируйте пароль

Нужен **Server Password / Пароль сервера** из этого окна OBS. Это пароль для подключения Freecam к OBS на вашем компьютере.

Если пароль скрыт, нажмите **Show Connect Info / Показать информацию о подключении**, если эта кнопка есть в вашей версии. Скопируйте значение пароля кнопкой копирования рядом с ним или выделите его и нажмите **Ctrl+C**. Названия могут немного отличаться между версиями OBS.

Можно задать свой пароль в поле **Server Password / Пароль сервера**. После изменения нажмите **Apply / Применить**, затем **OK**. Сохраните пароль у себя; отправлять его кому-либо не нужно.

## 5. Подключите Freecam

Вернитесь на вкладку мастера в браузере. Нажмите на поле **«Пароль OBS»** и вставьте скопированный пароль через **Ctrl+V**. В поле появятся точки — это нормально.

Нажмите **«Подключить OBS»**. Должна появиться надпись **«OBS подключён. Выберите сцену и камеру.»** Поле пароля очистится после подключения — это тоже нормально.

Если подключение не получилось, проверьте, что OBS открыт, сервер включён, порт совпадает, а пароль действительно скопирован.

## 6. Выберите готовую сцену и камеру

В списке **«Сцена для копирования»** выберите свою обычную сцену с игрой, чатом и виджетами. В списке **«Источник камеры»** выберите вебку из этой сцены. Для теста подойдёт отдельный ролик или картинка.

Нажмите **«Подготовить и открыть сцену»** и дождитесь сообщения о готовности. Freecam создаст копию композиции без выбранной камеры, сохранив оригинал. Вся композиция вместе с чатом и виджетами будет вписана в область стрима: они останутся видимыми после обработки расширением.

Если готовой сцены нет, выберите **«Новая сцена — только игра и камера»**, затем укажите два разных источника. Источники добавляются в OBS в панели **Sources / Источники → +**: **Game Capture / Захват игры**, **Video Capture Device / Устройство захвата видео**, **Media Source / Источник медиа**. После добавления снова нажмите «Подключить OBS», чтобы обновить списки.

## 7. Проверьте сцену

В OBS откроется новая сцена **Freecam**. Игра будет сверху слева, маленькая камера — снизу справа, рядом цветной маркер и анимированная подсказка установки. Такая компоновка до обработки расширением зрителя — ожидаемый результат.

Исходный холст **16:9** сохраняется. Выход OBS станет **1920×1080**. Исходные сцены и источники сохраняются. Freecam не запускает эфир или запись.

Приложение можно закрыть после подготовки. Для проверки на Twitch запускайте эфир вручную, когда будете готовы. Зрителю нужно установить расширение из папки **browser-extension** в архиве. Проверка на живом Twitch пока не завершена.

Подсказка встроена в приложение вместе со шрифтом и логотипом. При запуске она сохраняется в постоянную папку `%LOCALAPPDATA%\Freecam\assets` и проверяется по контрольной сумме. Она работает после закрытия Freecam и удаления временной папки архива. Браузерные виджеты и другие источники используются совместно с оригиналом; их содержимое обновляется как обычно.

## Если подсказка пропала в уже созданной сцене

Откройте новую версию Freecam и подключите OBS обычным способом. Нажмите **«Восстановить подсказки Freecam»**. Приложение проверит локальный файл, обновит пути только у своих подсказок и перезагрузит их в OBS. Сцену заново собирать не нужно.
