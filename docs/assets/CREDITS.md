# Материалы первой GIF

Первая GIF показывает работающий локальный обработчик Freecam. В общий кадр упакованы две отдельные записи, предоставленные пользователем для этой презентации:

- Геймплей: `dwitch_yb1vdrfq.opt.mp4`.
- Веб-камера: `bratishkin.opt.mp4`.

Изменения: короткие фрагменты, масштабирование до областей общего кадра, отключение звука и запись перемещения камеры в интерфейсе Freecam. Исходные видео не включены в репозиторий. Они не заявляются собственностью проекта; участие или поддержка продукта со стороны изображённых людей не подразумеваются.

Первая GIF содержит общий непрерывный восьмисекундный фрагмент обеих записей и заканчивается после демонстрации перемещения и размера. Лишний хвост вебки не используется. Кадры захватываются по фиксированной шкале времени, без повторного запуска исходного видео во время захвата.

Это демонстрация обработки видео, не запись живого Twitch-эфира. Для измерения совпадения кадров используется отдельный стенд со счётчиками.

Воспроизведение с локальными файлами:

```powershell
node scripts/prepare-presentation.mjs --game "путь/геймплей.mp4" --camera "путь/вебка.mp4" --game-offset 0
node scripts/generate-readme-preview.mjs
```
