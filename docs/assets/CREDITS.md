# Материалы презентаций Freecam

Презентации используют записи, предоставленные для проекта:

- Геймплей: dwitch_yb1vdrfq.opt.mp4.
- Веб-камера: bratishkin.opt.mp4.

Видеоматериалы сохраняют права своих владельцев. Участие или поддержка Freecam со стороны изображённых людей не подразумеваются. Исходные ролики не включены в репозиторий.

Главная демонстрация показывает распаковку фона из служебных SEI-данных того же видео. Для презентации подготовлен непрерывный фрагмент; фон извлекает браузерный декодер Freecam. Камера перемещается поверх восстановленной игры. Отдельный файл фона во время просмотра не загружается.

Это презентация функции на предоставленных записях, а не запись живого Twitch-плеера. Успешный живой тест на Twitch отмечен отдельно в статусе проекта.

Основной MP4: 30 FPS; GIF: 25 FPS. Схема принципа: 25 FPS. Декоративный курсор не используется. Ролики без звука. Пример выходной композиции показывает обычный полноразмерный кадр с игрой, чатом и вебкой; интерфейс OBS не изображён.

Оформление основано на материалах Freecam Drag и векторных ресурсах проекта. Шрифт Manrope используется по SIL Open Font License.
