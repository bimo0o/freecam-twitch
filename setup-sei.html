Подключение живой сцены OBS · ранняя нативная сборка.

1. Подключить OBS

OBS 33.0.1. Сначала установите модуль Freecam и перезапустите OBS. Эта сборка проверена на 1920×1080 при 30 FPS.

Сервис / Tools → Настройки сервера WebSocket / WebSocket Server Settings → включить сервер. Пароль находится в «Показать информацию о подключении / Show Connect Info».

Пароль используется только для соединения с OBS на этом компьютере. Не сохраняется.

2. Выбрать готовую сцену

Для этой сборки выберите камеру на верхнем уровне сцены, без поворота и режима границ. Исходная сцена и её источники сохраняются. Фон кодируется в 640×360; большая область будет менее детальной.

Остановите эфир и запись перед подготовкой. Кнопка не запускает трансляцию.
