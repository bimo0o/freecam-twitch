# freecam — Drag

Выбранное направление: округлая камера с курсором в негативном пространстве.

01-brand-essentials.png — визуальная база: горизонтальный и компактный логотип, знак, монохром и app icon.
02-symbol-glow-exploration.png — декоративное исследование знака со свечением; не использовать как готовую иконку.

Палитра: фон #100C17; акцент #C79AFF; текст #F5F0FF.
Шрифтовой ориентир: Manrope ExtraBold, строчные буквы.
Основная версия: знак слева, freecam справа.
Компактная версия: знак над названием.
Для маленьких иконок использовать знак без текста и свечения.
Охранное поле: не меньше четверти высоты знака.

Это растровая визуальная база. Изображения сгенерированы: перед выпуском нужны единый векторный мастер, точные одноцветные экспорты и проверка иконок в 16/24/32 px. Компоновки на листе являются дизайн-референсами.

## Реализация в продукте

Векторный мастер знака: `public/brand/symbol.svg`. Геометрия вручную адаптирована по направлению Drag; это единая рабочая версия для всех интерфейсов. Одноцветные варианты — `symbol-white.svg` и `symbol-black.svg`. Свечение отсутствует в малых иконках. Растровые листы выше остаются исходными референсами.

`scripts/generate-brand-assets.mjs` создаёт логотип с Manrope ExtraBold, PNG 16/24/32/48/128/256 и Windows ICO. Иконки размещены в `browser-extension/icons`, ресурсы интерфейса — в `public/brand`. Manrope поставляется без изменений по SIL OFL; рядом включены `OFL.txt` и `FONTLOG.txt`. Источник: [Google Fonts / Manrope](https://github.com/google/fonts/tree/main/ofl/manrope).
