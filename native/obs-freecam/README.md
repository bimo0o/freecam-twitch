# Freecam для OBS · 0.5.0 alpha

Модуль берёт фон под камерой из приватной копии готовой сцены. Он сжимает участок и добавляет его в H.264 / SEI штатного выхода OBS. Звук и видимый кадр идут через OBS. Второй канал и сервер раздачи камеры не нужны.

## Перед установкой

Тестовая сборка: **Windows x64, OBS 33.0.1, 1920×1080, 30 FPS**. Холст и выходное разрешение должны совпадать. Основной кодировщик должен выдавать H.264 Annex B. AV1 и HEVC не поддерживаются. Локально проверен x264, включая B-кадры; аппаратные кодировщики и живой выход Twitch этой версии требуют отдельного теста.

Камера должна находиться на верхнем уровне сцены, целиком внутри кадра, без поворота, отражения и режима границ. Режим границ OBS — **Без границ / No bounds**. Один источник камеры не должен повторяться в сцене. Вложенные камеры пока не поддерживаются.

## Установка и первый тест

1. Распакуйте **Freecam-OBS-0.5.0.zip** в обычную папку. Не запускайте файлы внутри окна архиватора.
2. **Закройте OBS.** Откройте **Install Freecam OBS.exe**, нажмите «Выбрать OBS и установить модуль» и выберите `obs64.exe` в папке `obs-studio/bin/64bit`. Установщик проверит версию и сохранит прежний модуль в резервный файл. Если папка защищена, запустите установщик от имени администратора.
3. Запустите OBS. Откройте **Сервис / Tools → Настройки сервера WebSocket / WebSocket Server Settings**. Включите сервер; защиту паролем оставьте включённой.
4. Нажмите **Показать информацию о подключении / Show Connect Info**. Скопируйте **пароль сервера**, а не ключ трансляции. Порт обычно **4455**.
5. Запустите **Freecam Native Setup.exe**. Введите пароль и порт, нажмите **Подключить**. Пароль не сохраняется и не отправляется за пределы компьютера.
6. Выберите **существующую сцену** с оформлением и её **камеру**. Нажмите **Подготовить Freecam**. Эфир и запись должны быть остановлены. Подготовка не запускает трансляцию.
7. В OBS нажмите **Начать запись / Start Recording**, запишите 10–20 секунд и остановите запись. В мастере откройте **панель расходов**: счётчик совпавших кадров должен расти. Панель также доступна через **Сервис / Tools → Freecam**.
8. После локальной проверки начните короткий тестовый эфир обычной кнопкой OBS. У зрителя установите Freecam 0.5.0, обновите канал и выберите **Source / Исходное**. Перетащите камеру; проверьте быстрые движения, звук и границы восстановленного участка.

Модуль не использует ключ трансляции. Исходная композиция сохраняется. Приватная копия исключает камеру только из захвата фона. После перезапуска OBS подготовьте Freecam снова. На других сценах восстановление приостанавливается. После добавления, удаления или перестановки источников остановите запись/эфир и повторите подготовку.

Для удаления закройте OBS и удалите только `obs-plugins/64bit/freecam-obs.dll` из выбранной установки. При необходимости верните резервный файл.

## Качество и расходы

Профиль фона: **640×360, x264 CRF 23**, без вспомогательных B-кадров. Большая закрытая область восстанавливается с меньшей детализацией. Жёсткого процентного ограничения площади у отправителя нет; порог зрителя меняет только его отображение.

Панель измеряет байты сжатых пакетов за последние две секунды: общий объём и добавленные Freecam данные. Передача и запись учитываются отдельно. Сетевые накладные расходы не включены. Процент статичной сцены нельзя переносить на динамичную игру.

Фон сопоставляется по времени кадра. Ожидание точного пакета ограничено **4 мс**; при его отсутствии передаётся маркер паузы, а не соседний фон. Это ограничение ожидания, а не замер полной задержки эфира или липсинка.

## Статус

**Alpha для проверки, не стабильный релиз.** Подтверждены настоящая запись OBS, восстановление из одного файла установленным расширением, B-кадры, выбор сцены через WebSocket и панель. Длительный эфир, переподключение, сложные вложенные композиции и аппаратные кодировщики требуют испытаний. В журнале тестового OBS остаётся один счётчик утечки при завершении; происхождение пока не установлено.

Перекодирование Twitch может удалить SEI. Source проверяется на конкретном эфире. Без расширения зритель видит обычную сцену.

## Исходники и сборка

Только нативный модуль лицензирован по **GPL-2.0-or-later**; полный текст — [COPYING](COPYING). Условия остальных компонентов остаются отдельными. Соответствующие исходники модуля и сценарий сборки находятся в `source` тестового комплекта.

Нужны Windows x64, установленный OBS 33.0.1 и MinGW-w64 GCC с C++17. Из корня исходников:

```powershell
git clone --depth 1 --branch 33.0.1 https://github.com/obsproject/obs-studio.git .tools/obs-sdk
powershell -ExecutionPolicy Bypass -File scripts/build-obs-plugin.ps1 -ObsRoot 'D:/obs-studio' -Compiler 'D:/mingw64/bin/g++.exe'
```

SDK: коммит `65c320b46e1af5c7a555161aea6182cdf7a8c524`. Результат — `artifacts/Freecam-OBS-0.5.0/freecam-obs.dll`. Сценарий создаёт минимальный `obsconfig.h` и связывается с `obs.dll` / `obs-frontend-api.dll` выбранной установки; OBS DLL не включены.

**Строгая фиксация версии:** замена пакета использует расположение счётчика ссылок OBS 33.0.1. Публичного конструктора пакета здесь нет. Модуль отказывается загружаться с другой версией OBS. Перенос требует проверки аллокатора и повторных тестов.

API: [обработка выходных пакетов OBS](https://docs.obsproject.com/reference-outputs#c.obs_output_add_packet_callback).
