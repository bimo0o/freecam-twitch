◈ freecam

Сцена готова за один шаг.

Выбрать игру и камеру — всё остальное Freecam расположит в OBS сам. Маркер и подсказка зрителям появятся автоматически.

1. Подключение OBS

Один раз включите WebSocket Server в OBS: Tools → WebSocket Server Settings. Защиту паролем оставьте включённой.

Пароль используется только для соединения с OBS на этом компьютере, не сохраняется и никуда не отправляется.

2. Игра и вебка

Будет создана новая сцена Freecam, а холст и выход OBS настроены на 1920×1080. Исходные сцены и источники сохранятся. Эфир и запись должны быть остановлены.
