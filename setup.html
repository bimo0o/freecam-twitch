freecam

Подготовим OBS вместе.

Выберите свою готовую сцену и камеру. Freecam сохранит чат и оформление, добавит маркер и короткую подсказку зрителям.

1. Подключение OBS

Откройте OBS и остановите эфир и запись. Затем выполните эти шаги один раз:

  1. Вверху окна OBS нажмите Tools / Сервис → WebSocket Server Settings / Настройки сервера WebSocket.
  2. Поставьте галочку Enable WebSocket server / Включить сервер WebSocket.
  3. Оставьте галочку Enable Authentication / Включить аутентификацию включённой.
  4. Найдите Server Password / Пароль сервера. Скопируйте именно этот пароль. Если он скрыт, используйте Show Connect Info / Показать информацию о подключении, если эта кнопка есть в вашей версии. Можно задать свой пароль в настройках OBS.
  5. Если изменяли настройки, нажмите Apply / Применить → OK. Вернитесь сюда, вставьте пароль в поле ниже и нажмите «Подключить OBS».
Не получается найти или скопировать пароль?

Это пароль сервера WebSocket в OBS. Нажмите кнопку копирования рядом с паролем либо выделите его и нажмите Ctrl+C. Здесь нажмите на поле «Пароль OBS» и затем Ctrl+V: появятся точки.

Можно задать свой пароль в поле Server Password / Пароль сервера в OBS и нажать Apply / Применить. В Freecam введите тот же пароль.

Если пункта WebSocket нет: Help / Справка → About / О программе. Нужен OBS 28 или новее. Названия пунктов могут немного отличаться.

Обычно порт менять не нужно: оставьте 4455. Если в OBS указан другой Server Port / Порт сервера, введите его ниже.Пароль используется только для соединения с OBS на этом компьютере, не сохраняется и никуда не отправляется.

Пропала подсказка в OBS?

Восстановите её в уже созданных сценах Freecam. Заново собирать сцену не нужно.

2. Готовая сцена и вебка

Выберите свою готовую сцену. Freecam создаст отдельную копию и впишет всё оформление вместе с чатом и виджетами в область стрима. Вебка будет вынесена в отдельную область; исходная сцена сохранится.

Моих источников нет в списке

В OBS найдите панель Sources / Источники и нажмите +. Для игры выберите Game Capture / Захват игры, для камеры — Video Capture Device / Устройство захвата видео. Для теста подойдёт отдельный ролик: Media Source / Источник медиа.

После добавления источников снова нажмите «Подключить OBS» вверху мастера, чтобы обновить списки.

Будет создана новая сцена Freecam, а выход OBS настроен на 1920×1080. Исходный холст 16:9 сохраняется. Исходные сцены и источники сохранятся. Эфир и запись должны быть остановлены.
